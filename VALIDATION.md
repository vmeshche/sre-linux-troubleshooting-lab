# Проверка сценариев

Проверено **9 октября 2026 года** на ARM64:

| Компонент | Окружение |
|---|---|
| Userspace | Ubuntu 26.04.1 LTS (образ ubuntu:26.04) |
| PID 1 | systemd 259.5-0ubuntu3.4 |
| Ядро | 6.12.76-linuxkit, Docker Desktop на macOS |
| Контейнер | Отдельный, privileged; собственные PID и cgroup namespace |
| strace | 6.19 |
| lsof | 4.99.4 |
| perf | 7.0.14; пакет linux-perf 7.0.0-38.38 |

## Пройденные проверки

- Сборка четырёх C-примеров с `-Wall -Wextra`, установка и проверка unit-файлов через `systemd-analyze verify`.
- Подготовка стенда и проверка окружения, в том числе из обычной учётной записи через sudo.
- Конфигурация: неуспешный старт, ENOENT с реальным путём, успешное исправление, EACCES под `lk7-demo`, повторный успех.
- Порт: old application, ошибка Address already in use, совпадение PID слушателя с unit, смена на new application.
- FIFO: подключение strace к ожидающему процессу, доставка строки, наблюдение read/write, отключение трассировщика при живой службе.
- Лог: файл 16 MiB, удаление имени, `NLINK=0` и размер через FD, переоткрытие по SIGUSR1, исчезновение удалённого объекта из lsof.
- CPU: работающий вычислительный процесс, ограниченная трассировка, perf stat, perf record, обнаружение `mix_numbers` в report.
- Повторный сброс без ошибки и успешная проверка исходного состояния.

## Границы проверки

Это проверка сценариев Linux с настоящим systemd, **не проверка установки VirtualBox**. Драйверы, ARM64/AMD64-гипервизор, SSH и аппаратные события perf на конкретных ноутбуках здесь не проверялись. Примеры используют переносимый C и собираются локально, однако отдельный прогон на AMD64 не выполнялся.

Контейнер использовал ядро LinuxKit, а не штатное ядро Ubuntu VM. Поэтому имена WCHAN, доступные события perf, часть служебного вывода и точные времена могут отличаться. Сценарий CPU содержит запасной разбор реального сохранённого профиля.

Неблокирующие сообщения нашего perf: `Failed to open /proc/schedstat` при записи и отсутствие `tips.txt` при просмотре. Запись при этом завершилась: 488 выборок, потерянных выборок 0, символ `mix_numbers` найден. Сохранённый вывод не скрывает эти особенности.
